# 0.2.0 图像回归与自动边框

## 本轮修复

旧版默认 10× 最小直径为整图短边的 1.2%。在 1440 px 图上约为 17 px，用户给出的相差环状细胞常只有约 6–12 px。大范围背景估计还会把亮网格之间的暗区当作大对象，导致小细胞漏检、标记圆过大。

新版使用精细尺度对比度恢复暗环/亮目标，一像素闭运算维持接触轮廓，按紧凑程度、局部对比度、连通域支撑面积和尺寸筛选。默认从候选中估计直径，仍提供手动范围。没有使用分水岭拆开团块，也没有通过整条擦除网格来切断压线对象。检测在整图完成，再按对象范围与所选分区判断计数。

边框与细胞独立检测：提取明/暗两种线条响应，检查等距重复网格，拟合四边，再将分区投影到四边形中。中央 20 个细格间隔表示 5×5 中格参考；完整九宫格必须另有可见外框证据。显微镜圆形视野只作可见性筛选。三线束参考其中线。四角 4×4 分格仅作为大格候选，仍须按实物和角位确认。

## 原始附件的本地结果

使用正式 Swift 源码、CoreGraphics 灰度转换，处理用户提供的 1440×1440 JPEG。原图及派生诊断图只保留本机，没有提交 GitHub。

- 自动定位中央密集网格，四角大致为 (387,547)、(986,551)、(986,1164)、(373,1156) px；实际保存的是归一化四边形。
- 未确认完整九宫格外框，不把中央区域当成 9 mm²，也不自动归入 10× 四角大格。
- 自动估计细胞直径约 12 px。
- 同一自动中央参考范围：旧版 69 个候选，新版 207 个候选。
- 红细胞标准四角加中心五中格：新版 39 个候选；选择全部 25 中格时统计整个中央区域。
- 固定局部裁切 (390,560,200,200) px，选定 19 个清晰对象，用 7 px 中心距离作一对一匹配：旧版 4/19，新版 19/19。相连的清晰双/三细胞团块各作为一个对象。

上述局部对象是开发时人工选择的回归参照，**不是独立评测集**；没有穷尽局部全部目标，没有做整图真值标注，也未测量全图 precision/recall。207/39 是候选数量，不是确证细胞数；不能用数量增加推断全图准确率。仍可看到少量微小伪影和模糊对象，需放大增删校正。

## 本地复现

不依赖 Python、OpenCV 或模型下载即可执行正式 Swift 检测路径：

```sh
swiftc -O Sources/CellCounterCore/*.swift scripts/analyze_image.swift -o /tmp/cellscope-analyze
/tmp/cellscope-analyze /path/to/image.jpg /tmp/result.json redBloodCells
```

支持 `redBloodCells`、`overview`、`singleLarge`、`custom`。JSON 包含网格四角、所选分格候选、完整参考范围候选和估计直径。模式不匹配时计数为 null，不套用默认框假装成功。`custom` 可使用定位到的参考边框，物理面积仍需自行确认。

## 验证与使用边界

21 项核心测试覆盖数值计算、原有压线/团块行为、小型相差环、亮网格交点过滤、明/暗网格、中央网格被裁切时拒绝完整九宫格、完整外框证据、三线中线、四角大格、圆形视野/空白拒绝、四边形映射和旧参数兼容。iOS UI 流程另验证自动定位后清空面积确认，以及原有三模式、四角平均、补标/删除/撤销、保存与重启。

自动定位适用于基本放正、线条完整且分辨率足够的图像，四边局部拟合可适配轻微倾斜。明显旋转、透视严重、格线缺失或曝光不均时可能失败；请重拍或手动框选。自动拟合并不证明实物的物理尺寸、板型或腔室深度，面积仍需人工确认。

四边形下的对象边缘使用图像轴向包围框投影后的范围，靠近倾斜边界时较保守。严重模糊、过大/细长团块、杂质及极低对比度目标可能漏检或误检。尚未在物理 iPhone 上验证目镜拍摄与处理耗时，没有完成不同设备、细胞类型、浓度和照明条件的准确率评估。
