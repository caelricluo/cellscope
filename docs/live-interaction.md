# 0.3.0 手机操作与实时计算

## 边框编辑

点击「边框」直接进入全屏编辑。四个角、四条边提供固定屏幕尺寸的触点；放大图像后触点仍保持相同大小。拖动角点保留四边形的透视形状，拖动边线同时移动其两个端点，拖动框内整体平移。拖动时显示局部放大镜和十字落点。双指缩放或移动图像。

底部可选择整体、角点或边线，使用方向键按 1 px / 5 px 微调，支持按住连续移动。重置恢复自动定位边框或初始区域。调整后自动重新识别，不需重画矩形或点击重新检测。

框点限制在图像内；整体平移在图像边缘停止且不改变框形；交叉、翻转或退化调整被忽略。

## 实时参数

检测参数面板上方保留可缩放的图像、标记、细胞数、浓度和取液量，下方调节灵敏度、明暗模式、自动/手动尺寸。连续修改合并为 180 ms 的一次请求，后续修改取消旧任务；只有当前图像、角位、区域、分格和参数版本的结果可以写回。

图像灰度缓存复用，背景识别在后台运行。取消检查分布在高斯处理行和连通域循环中，避免快速拖动滑块时旧计算堆积。结果更新期间保留上次完成的图像标记与数值，并显示「更新中」。打开参数面板后的连续修改只记录一次标记撤销快照。

分格选择变化后自动计数。稀释倍数、面积、深度、原液体积和目标细胞数直接更新计算，不触发图像处理。

## 计算与记录

移除面积确认和逐一复核两个开关，以及「待复核」结果状态。有效参数和识别结果直接用于浓度、总细胞数与取液量计算；10× 模式四张图计数完成后自动平均。保存和导出不再读取历史确认标志。

旧记录中的 `areaConfirmed`、`reviewed` 仍保留兼容读取，新记录写为 false，不声称用户执行过确认或人工复核。恢复旧记录后按相同的实时逻辑计算。CSV 移除「人工复核」状态与用途提示。操作页面及指南仅保留操作说明、计数规则和实际输入错误。

## 验证

- 24 项核心测试通过，新增整体平移约束、角点/边线透视保持、拒绝交叉，以及自动尺寸忽略未使用手动范围测试。
- 5 项 UI 流程分别通过：自动定位直接计算；增删撤销与保存恢复；边框拖动、微调、重置及重计数；参数面板实时 49→0→49 及浓度同步；三模式与四角平均。
- 边框微调、自动计算等 4 项流程在 `TestResults/LiveInteraction.xcresult` 通过；实时参数流程最终在 `TestResults/LiveParametersFixed.xcresult` 通过。首次参数测试点中开关行的空白处，修正为实际开关位置后通过。
- iOS Simulator、Mac Catalyst 和 iPhoneOS arm64 Release 编译通过，未签名 IPA 版本 0.3.0（build 3）。
