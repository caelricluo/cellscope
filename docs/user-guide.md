# User guide / 使用指南

## English

**Acquire.** Select a counting mode, then capture a microscope image or import from the photo library. The Mac preview additionally accepts local files.

**Align.** Grid boundaries are located automatically. Select **Frame** to enter the full-screen editor. Drag any corner or side, or drag inside to move the entire frame. The loupe shows the adjustment point. Use 1 px or 5 px arrow controls for fine adjustments. Pinch or use two fingers to pan the image.

**Mode choice.** Central-grid detection offers an RBC shortcut without blocking 4×, 10× or custom mode. When no matching frame is found, the selected mode and current frame remain in use.

**Count.** Open **Detection settings** to adjust sensitivity, object polarity and automatic/manual cell size. The image, markers, count, concentration and required volume remain visible. Select **Auto** to combine bright and dark cell support. **Dark** and **Bright** select a single polarity. The upper sensitivity range lowers the noise-relative contrast threshold and recovers smaller, incomplete rims. Results refresh automatically after changes. **Add**, **Delete** and **Undo** edit the markers directly.

**Reset.** Reset chamber parameters restores the current selected area, 0.1 mm depth, dilution 2 and stock volume 1 mL. Images, frames and target count are preserved. The detection panel has a separate Reset control.

**Calculate.** Enter chamber depth, total dilution, stock volume and target cell count. Selected grid squares determine the counting area; custom mode accepts a manually entered area. Results update without confirmation switches.

**Four corners.** Capture A1, A3, C1 and C3 separately. Each image retains its own frame, count and settings. The current result uses the unrounded mean of the counted corners and their total area. Once complete, all four are averaged. Concentration and total stock cells remain visible during acquisition.

**Save and export.** Save a sample to the on-device library. Export creates a UTF-8 CSV report and annotated images; a four-corner set exports four images.

**Rules.** Include top/left boundary objects and exclude bottom/right boundary objects. Use the middle ruling of a triple line. Count each connected cluster as one object.

**Language.** The interface and export labels follow the iOS app language: English or Simplified Chinese.

## 简体中文

**采集。** 选择计数模式后，拍摄显微图像或从相册导入。Mac 预览另支持本机文件导入。

**对齐。** 图像导入后自动定位网格。点击「边框」进入全屏编辑，拖动角点、边线或框内区域；放大镜显示调整落点。使用 1 px 或 5 px 方向键精调，双指缩放和移动图像。

**模式选择。** 检测到中央网格时提供红细胞模式快捷按钮，4×、10× 和自定义模式继续可用。没有匹配边框时，保留所选模式和当前边框继续计数。

**计数。** 打开「检测参数」调整灵敏度、目标明暗和自动/手动尺寸。同屏保留图像、标记、数量、浓度和取液量，选择「自动」合并亮暗细胞轮廓；「深色」或「浅色」使用单一明暗响应。高灵敏度区间进一步降低相对噪声阈值，并恢复较小、不完整的轮廓。修改后自动更新。使用补标、删除和撤销直接编辑标记。

**重置。** 「重置计数板参数」恢复当前选格面积、深度 0.1 mm、稀释倍数 2 和原液体积 1 mL，保留图片、边框及目标细胞数。识别参数面板另有重置入口。

**计算。** 输入腔室深度、总稀释倍数、原液体积和目标细胞数。所选网格决定面积，自定义模式手动输入面积。结果直接更新，无确认开关。

**四角。** 分别采集 A1、A3、C1、C3，各图保留独立边框、计数和参数。采集过程中按已计数角位和对应总面积实时平均，显示浓度与原液总细胞数；四角完成后使用全部四角的未经取整平均计数。

**保存与导出。** 样本保存至本机记录。导出生成 UTF-8 CSV 报告和标记图，四角样本导出四张图。

**规则。** 记上不记下，记左不记右；三线边界取中线。每个相连团块计作一个对象。

**语言。** 界面与导出标签根据 iOS App 语言显示英文或简体中文。
